# Пиксельная изометрия «Танкороста» (утверждено пользователем 2026-10-20)

Эталон — первая ступень (игрушечный полигон) и переход на вторую, ветка `main` репозитория `tanks163`
(Pages: https://podvorotshort-source.github.io/tanks163/). Референс пользователя — сочный пиксель-арт:
трава с травинками, тропы, плитка, пруд с камнями и кувшинками, кирпичи, бронеящики, жёлтый танк с тёмно-синей
отделкой, красные вражеские игрушки. **Без «бластеров» и голубых/золотых светящихся огоньков** у снарядов.
Ассеты из папки `art/` **не использовать** — всё рисуется кодом.

## Правила пиксель-арта (держать везде)

- **Плотность: 1 воксель ≈ 1 пиксель** при обычном размере объекта. Танк игрока 64 ед. = модель ~48–56 вокселей в длину.
  Мелкий враг 20 ед. → модель ~16–20 вокселей. Большое — больше вокселей, а не крупнее воксели (босс = `up2`, ×2 детали).
- Рампы со **сдвигом оттенка** (тень → синий/фиолетовый, свет → жёлтый), шаг тона 15–25 %; соседние цвета разной яркости.
- Крупные пятна тона без шума; фактура — **штампами** (травинка, кустик, цветок, камешек, рябь, кувшинка, булыжник).
- Кромки: тень под кромкой травы на тропе, тёмная полоса воды под берегом, у приподнятых областей — **боковая грань** и падающая тень.
- Контур — тёмно-фиолетовый `#1a1124` по перепаду глубины (выходит снаружи силуэта).
- Огонь — **никогда не диски/кружки**: только спрайты из `flame.ts` (по образцу листа эффектов и референса: гарь с угольками, отдельные языки с тёмной кромкой, клубы с бело-жёлтым ядром). Набор кадров держать малым (кеш), проверять `__tk.perf()` (`world`, `sprites`); поджечь землю — `__tk.ignite(dx, r)`, вокруг блока — `__tk.igniteProp('brick', r)`. Эффекты, стоящие в мире (клубы, дым, пламя, гарь), — только в 3D-слое, иначе лезут на блоки; в 2D-холсте остаются мелочи (искры, угольки, обломки, кольца, цифры). Огонь не горит под твёрдыми препятствиями (`FireGrid.blocked`).
- Читаемость важнее детали: деталь подчёркивает форму (траки, катки, дульный тормоз, решётки, трубы, ящики, антенна закреплена).

## Танки и цвет

- Облик I (`heroI`): 1P жёлтый (`yel`), 2P зелёный (`green_l`), отделка `navy`; широкие гусеницы (`track()`:
  лента, грунтозацепы через 3 вокселя, катки на внешней стороне, ведущая звезда). **Корпус и орудие — по классу**, все в одном
  масштабе (`size` общий: разведчик меньше, тяжёлый крупнее): разведчик — низкий узкий клин, 4 катка, маленькая башня,
  длинная тонкая `barrel()`, две антенны, полоса по оси; штурмовик — средний, коробчатая башня, короткая толстая `howitzer()`
  (фугас), дымовые мортирки, полки с ЗИП; тяжёлый — широкий высокий, бронеэкраны с заклёпками, 6 катков, приземистая башня
  с `flamer()` (сопло, топливная трубка, светящийся запальник), баки смеси на корме. В облике II корпус — форма генерала,
  орудия по классу (спаренные: длинные тонкие / гаубицы / огнемёты).
- **Облик следующего поколения = форма поглощённого босса.** Пример: босс I — серые бронеплиты с **красным** магматическим
  свечением (`glow_r`), двойная пушка, заводной ключ (часть `key`, ось x) — слабое место. Игрок после поглощения — та же форма
  (`heroII`), свечение его цвета: 1P `glow_y`, 2P `glow_g`. Так цвета игроков сохраняются.
- Враги — «вражеская армия»: красный (`red`, `red_d`), белые полосы, красные огоньки `glow_r`.
- Свечение — только материалы из `GLOW` (`vox.ts`); палитра — `PAL`.

## Земля (`paint.ts`)

`paintStage(s, seed)` — генератор: (1) материал и тон каждого пикселя (`sample` → стиль ступени; реликвия прежней ступени
рисуется её же стилем в новом масштабе; за ареной — мир следующей ступени, альфа 128; дальше 260 ед. — пусто),
(2) соседские правки, (3) штампы, (4) боковые грани арены (7 px, слои почвы) и реликвии (3 px) с тенью, (5) цвет.
Пруды — из препятствий `water` (нарисованы, 3D-модели нет). Стили: `toy` (ступень I: трава, тропы, пруды), `nursery` (II: доски, ковёр, коврик),
остальные пока общий `cellAt` + рампа — **перерисовать по образцу toy/nursery**.
Оптимизация: без выделений памяти в циклах, без `Math.hypot`, кэш реликвий и прудов.

## Рост и переход (симуляция + кат-сцена)

- В бою танк не растёт: `TANK_SIZE = 64`. Сила — от `Sim.vsize` (28→112 за ступень по уровням); враги подбираются по `vsize`
  и ужимаются (`Sim.compress`) — пропорции и баланс прежние.
- После босса: обломки остаются (`TransView.wreck`), танк въезжает (TR_DRIVE0..TR_DRIVE1), поглощает (до TR_ABSORB1): искры
  в танк, рост ×4, смена облика; камера отъезжает ×4 (до TRANSITION_SWITCH); поля старой арены гаснут, затем сама старая арена —
  под ней новая ступень, где прежнее поле — заново нарисованная реликвия. Трофей — `BOSS_ABILITY` (`sim/content/classes.ts`).
- Босс в бою — масштаб не меняется, кадр смещается к нему; падение сверху с ударом и пылью; мишень на слабом месте.

## Цикл работы (не пропускать проверку глазами)

```bash
npm run build
GPU=1 npx tsx e2e/shot.ts --q "dev=play&cls=assault&seed=3&stage=0" --steps "wait:4000;shot:a" --prefix v
GPU=1 npx tsx e2e/shot.ts --q "dev=models&g=one&k=tank:assault:1:0,boss:bossGeneral&zoom=3&a=0.6" --steps "wait:2500;shot:m" --prefix m
GPU=1 npx tsx e2e/shot.ts --q "dev=play&cls=assault&seed=3&stage=0" --steps "wait:4000;eval:(__tk.god(), __tk.skipStage());wait:3000;shot:t1;wait:3000;shot:t2;wait:3000;shot:t3" --prefix tr
```
Смотреть PNG в `e2e/out` (крупно — обрезать и увеличить Pillow ×3 NEAREST), сравнивать с референсом, править, повторять.
Витрина: `?dev=models&g=s0..s7|tanks|bosses|one&k=…&a=<угол>&zoom=…`. Отладка: `window.__tk` (god, boss, skipStage, spawn, perf).
В `eval` внутри `--steps` точку с запятой писать как `%3B`.

## Что дальше (по порядку пользователя: сначала графика, потом баланс)

1. Враги и игрушки ступени II в той же плотности и стиле; облик III = форма Пульт-тирана (+ трофей «Перехват управления»).
2. Ступени III–VIII: свой стиль земли в `paint.ts`, враги, препятствия, боссы (серые плиты + красное свечение у врага),
   облики IV–VIII и трофеи (вихрь, ледяной фронт, раскатка, ковровая бомбардировка, гарнизон).
3. Интерфейс в стиле референса (полоски здоровья/энергии, кнопки Q/E/R), финал с глобусом в новой графике.
4. Баланс — только после графики (бои с боссами сейчас длиннее: ~100 с у генерала).
