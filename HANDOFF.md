# HANDOFF — как продолжить работу над «Танкоростом»

Читать в начале каждой новой сессии вместе с `GAME_SPEC.md` (ответы пользователя),
`docs/DESIGN.md` (дизайн), `docs/REQUIREMENTS.md` (чек-лист ТЗ), `SYSTEMS.md` (статус).

## Запуск

```bash
npm install
npm run build        # dist/index.html — один файл, открывается двойным кликом
npm run dev          # http://localhost:5173 (разработка)
npm test             # Vitest: правила кооператива, оружие, синергии, сохранения
npx tsx e2e/shot.ts --q "dev=play&cls=assault,heavy" --steps "wait:1500;shot:a"   # скриншот из браузера
npx tsx e2e/gamepad.ts            # эмуляция DualSense/DS4
npx tsx tools/sim.ts --runs 2 --classes assault,heavy -v   # балансный прогон ботами
npx tsx tools/art-preview.ts tanks|tiers|enemies|bosses|props|icons   # PNG спрайтов в tools/out/
npx tsx tools/slice.ts art/*.png  # нарезка сгенерированных листов → assets/sprites (см. art/README.md)
npx tsx tools/fake-sheet.ts       # тестовые листы «как от генератора» для проверки нарезки
```

Отладка в браузере: `window.__tk` (state(), perf(), xp(n), skipStage(), boss(), god(), spawn(id,n), give(p,w), power(id), speed(k)).
URL-параметры: `?dev=play&cls=scout,heavy&stage=2&seed=7` — сразу в бой; `?dev=gallery` — галерея спрайтов;
`?dev=art&page=0..5` — витрина всей графики (зелёным — что уже из внешних картинок);
`?dev=tune` — инструмент масштабов графики (`src/debug/tune.ts`, множители в `assets/sprites/scales.json`, `src/gfx/artScale.ts`).
Производительность честно мерить с GPU: `GPU=1 npx tsx e2e/shot.ts ...` (без флага Chromium рисует программно и FPS занижен вдвое).

## Структура

- `src/sim/**` — детерминированная симуляция без DOM (бой, враги, боссы, режиссёр, улучшения, бонусы). Гоняется в Node ботами (`src/sim/bot.ts`).
- `src/gfx/**` — графика: `raster.ts` (растеризатор форм, 32 угла без размытия), `art/*` (танки с 8 поколениями облика, враги, боссы, препятствия, земля, иконки), `ext.ts` (**внешние картинки** из `assets/sprites` поверх процедурных), `sprites.ts` (кеш), `font.ts` (пиксельные шрифты с кириллицей), `screen.ts` (два холста: мир и интерфейс).
- `src/client/**` — игровая сцена: камера, куски земли, частицы, свет, HUD, выбор улучшений, пауза, кинематографичный переход масштаба.
- `src/ui/**` — меню: титул, подготовка (2P присоединяется кнопкой), база (мастерская/арсенал/исследования/гараж/трофеи), итоги, настройки, управление.
- `src/meta/**` — сохранения (контрольная сумма + резервная копия), мета-прогрессия, настройки.
- `src/audio/**` — синтез звуков и процедурная музыка.

## Ключевые решения

- Всё оружие стреляет само; игрок — движение + до 3 способностей (слот 1 — класс).
- Рост: экспонента `growE` (+1/12 за уровень, предел ступень+1.08), размер танка в локальных
  единицах = 28·4^(growE−ступень); камера держит танк ~28 px. Сила ∝ (абсолютный размер)^1.6.
- Переход: камера отъезжает ×24, мир ступени n+1 = мир n × 4; старая арена — «реликвия» в новом
  мире, её препятствия переезжают уменьшенными (давятся). Танк не меняет абсолютный размер.
- После перехода — смена поколения облика танка (`client/tiers.ts`, `gfx/art/tanks.ts`).
- **ГРАФИКА — НОВОЕ НАПРАВЛЕНИЕ (утверждено 2026-10-19): 3D в стиле Clash Royale.** Всё о нём — в навыке
  `.claude/skills/lowpoly-3d/SKILL.md` (читать перед любой работой с графикой): модели собираются скриптами
  в Blender (`models3d/`), проверяются в Three.js, утверждённая сцена ступени I — `docs/scene-t1/index.html`.
  Нынешняя 2D-графика (`src/gfx/**`, спрайты из `art/` и `assets/sprites`, `?dev=tune`) — **устаревает**:
  следующий большой шаг — заменить вывод мира на Three.js, оставив логику `src/sim/` без изменений.
  Пиксель-арт и ChatGPT-листы (`docs/ART_PROMPTS.md`) больше не развивать.
- Мир рисуется в своём холсте высокого разрешения (`renderWorld`), интерфейс и подписи — в своём
  (`render`); координаты мира для интерфейса — через `GameScene.ucam`.

### Известные проблемы и TODO
- Баланс в работе: опыт/уровни, прочность боссов, длительность ступеней (цель ~60 мин).
  Боты (`src/sim/bot.ts`) слабее человека — полный забег ими пока не проходится.
- Реальные геймпады не проверены (только эмуляция) — нужна ручная проверка пользователем.
- Графика: следующий шаг — остальные враги ступени I и босс «Заводной генерал» в 3D (по одному, с показом
  пользователю), затем встраивание Three.js в игру и сенсорное управление (см. план в навыке `lowpoly-3d`).
- Интерфейс остаётся в низком разрешении (иконки 18 px) — при желании пользователя можно поднять.
