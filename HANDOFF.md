# HANDOFF — как продолжить работу над «Танкоростом»

Читать в начале каждой новой сессии вместе с `GAME_SPEC.md` (ответы пользователя),
`docs/DESIGN.md` (дизайн), `docs/REQUIREMENTS.md` (чек-лист ТЗ), `SYSTEMS.md` (статус).

## Запуск

```bash
npm install
npm run build        # dist/index.html — один файл, открывается двойным кликом
npm run dev          # http://localhost:5173 (разработка)
npm test             # Vitest: правила кооператива, оружие, синергии, сохранения
npx tsx e2e/shot.ts --q "dev=play&cls=assault,heavy" --steps "wait:1500;shot:a"   # скриншот из браузера
npx tsx e2e/gamepad.ts            # эмуляция DualSense/DS4
npx tsx tools/sim.ts --runs 2 --classes assault,heavy -v   # балансный прогон ботами
npx tsx tools/slice.ts art/10_icons*.png art/11_effects.png  # нарезка листов иконок и эффектов → assets/sprites
GPU=1 npx tsx e2e/shot.ts --q "dev=models&g=s0&zoom=2" --steps "wait:2500;shot:a"   # витрина моделей ступени
```

Отладка в браузере: `window.__tk` (state(), perf(), xp(n), skipStage(), boss(), god(), spawn(id,n), give(p,w), power(id), speed(k)).
URL-параметры: `?dev=play&cls=scout,heavy&stage=2&seed=7` — сразу в бой;
`?dev=models&g=tanks|s0..s7|bosses&zoom=2` — витрина воксельных моделей; `?dev=models&g=one&k=boss:bossTyrant&a=0.6` — одна модель под углом.
Производительность честно мерить с GPU: `GPU=1 npx tsx e2e/shot.ts ...` (без флага Chromium рисует программно и FPS занижен вдвое).

## Структура

- `src/sim/**` — детерминированная симуляция без DOM (бой, враги, боссы, режиссёр, улучшения, бонусы). Гоняется в Node ботами (`src/sim/bot.ts`).
- `src/iso/**` — **графика мира: изометрический пиксель-арт** (Three.js в низком разрешении + контур).
  `vox.ts` (палитра, воксельная сетка, построение сеток), `models/stage0..6.ts` (все враги, боссы, препятствия по ступеням),
  `models/tanks.ts` (танки игроков: 3 класса × 8 поколений), `models/deco.ts` (травинки, камешки…), `ground.ts` (земля ступеней и реликвий),
  `renderer.ts` (вывод, контур, свет), `world.ts` (связь с симуляцией), `ending.ts` (финал с глобусом), `showcase.ts`/`portrait.ts` (меню).
- `src/gfx/**` — интерфейс: `font.ts` (пиксельные шрифты с кириллицей), `ext.ts` (иконки и кадры эффектов из `assets/sprites`), `screen.ts` (холсты: 3D, мир, интерфейс).
- `src/client/**` — игровая сцена: камера, куски земли, частицы, свет, HUD, выбор улучшений, пауза, кинематографичный переход масштаба.
- `src/ui/**` — меню: титул, подготовка (2P присоединяется кнопкой), база (мастерская/арсенал/исследования/гараж/трофеи), итоги, настройки, управление.
- `src/meta/**` — сохранения (контрольная сумма + резервная копия), мета-прогрессия, настройки.
- `src/audio/**` — синтез звуков и процедурная музыка.

## Ключевые решения

- Всё оружие стреляет само; игрок — движение + до 3 способностей (слот 1 — класс).
- Рост: экспонента `growE` (+1/12 за уровень, предел ступень+1.08), размер танка в локальных
  единицах = 28·4^(growE−ступень); камера держит танк ~28 px. Сила ∝ (абсолютный размер)^1.6.
- Переход: камера отъезжает ×24, мир ступени n+1 = мир n × 4; старая арена — «реликвия» в новом
  мире, её препятствия переезжают уменьшенными (давятся). Танк не меняет абсолютный размер.
- После перехода — смена поколения облика танка (`client/tiers.ts`, `iso/models/tanks.ts`).
- **ГРАФИКА (v2, 2026-10-20): изометрический пиксель-арт по референсу пользователя.**
  Масштаб камеры в бою постоянный: `ART_Z = 1` пиксель кадра на единицу мира, кадр ~360 строк (крупный пиксель ×3 на 1080p).
  Земля — попиксельная картинка ступени (`src/iso/paint.ts`): рампы со сдвигом оттенка, штампы (травинки, цветы,
  камешки, рябь, кувшинки, булыжники), боковые грани приподнятых арен с тенью. Рисуется ~1 с, следующая ступень —
  в фоне во время боя (`IsoWorld.prebuild/pump`). Объекты — воксельные модели (~1 воксель = 1 пиксель),
  «мультяшный» свет с цветными тенями и контур (`src/iso/renderer.ts`). Танки: `src/iso/models/hero.ts` (облики I и II),
  враги I ступени — `army.ts`; облики III–VIII и враги ступеней II–VIII — ещё прежние модели (переделать по тем же правилам).
- **Рост и переход (v2):** в бою танк не растёт (физический размер `TANK_SIZE = 64`); сила растёт с уровнями через
  «виртуальный» размер `Sim.vsize`, враги подбираются по нему и ужимаются в тех же пропорциях (`Sim.compress`).
  После победы танк въезжает в обломки босса и поглощает их: облик, сила и размер ×4 (облик следующего поколения = форма
  босса, свечение — цвет игрока: 1P жёлтый, 2P зелёный, у босса — красное). Камера отъезжает ×4; старая арена гаснет,
  а под ней — новая ступень, где прежнее поле заново нарисовано «реликвией» в новом масштабе. Трофей — способность босса
  (`BOSS_ABILITY` в `sim/content/classes.ts`, пока есть «Раскалённый залп» генерала; при занятых слотах — выбор замены).
- Управление по экрану: «вправо» = вправо (поворот ввода на 45° в `client/game.ts`). Способность «Дым» удалена.
- Ассеты из папки `art/` больше не используются: значки и эффекты рисуются кодом (`gfx/art/icons.ts`, частицы).
- **Запасной вариант — 3D в стиле Clash Royale** (ветка `graphics-3d`, навык `.claude/skills/lowpoly-3d`,
  скрипты Blender в `models3d/`, утверждённая сцена `docs/scene-t1/index.html`). Если пиксельная изометрия
  не понравится — возвращаться к нему.
- Мир рисуется в своём холсте высокого разрешения (`renderWorld`), интерфейс и подписи — в своём
  (`render`); координаты мира для интерфейса — через `GameScene.ucam`.

## Состояние / что осталось

См. `SYSTEMS.md` и раздел «Известные проблемы» ниже.

### Известные проблемы и TODO
- Баланс в работе: опыт/уровни, прочность боссов, длительность ступеней (цель ~60 мин).
  Боты (`src/sim/bot.ts`) слабее человека — полный забег ими пока не проходится.
- Реальные геймпады не проверены (только эмуляция) — нужна ручная проверка пользователем.
- Графика: следующий шаг — остальные враги ступени I и босс «Заводной генерал» в 3D (по одному, с показом
  пользователю), затем встраивание Three.js в игру и сенсорное управление (см. план в навыке `lowpoly-3d`).
- Интерфейс остаётся в низком разрешении (иконки 18 px) — при желании пользователя можно поднять.
