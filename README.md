# Танкорост

Танковый рогалик на одного или двоих: игрушечный танк растёт от полигона на ковре до планетарного титана.
Восемь ступеней мира, каждая в четыре раза больше предыдущей, восемь боссов и финал с глобусом на детском столе.

**Играть в браузере:** https://podvorotshort-source.github.io/tanks163/

Графика: изометрический пиксель-арт. Воксельные модели рисует 3D-вывод в низком разрешении с контуром,
поэтому масштаб и переходы между мирами не ломают пиксели.

## Управление

- 1P: WASD — движение, Пробел / E / Q — способности; Esc — пауза.
- 2P: стрелки и Num0 (или геймпад). Второй игрок присоединяется на экране подготовки.
- Оружие стреляет само.

## Сборка

```bash
npm install
npm run build   # dist/index.html — один файл, открывается двойным кликом
npm run dev     # http://localhost:5173
npm test
```

Подробности для разработки — в `HANDOFF.md`.
