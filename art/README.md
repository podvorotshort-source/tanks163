# Сюда — сгенерированные листы спрайтов

1. Сгенерируйте листы по `docs/ART_PROMPTS.md`.
2. Сохраните их в эту папку **с именами из заголовков** промтов: `01_hulls_1-4.png`, `03_turrets.png`, `13_ground_3.png` и т. д. (PNG, WebP или JPEG). Вариант перегенерации можно назвать `01_hulls_1-4 (2).png`.
3. Скажите мне — я нарежу их командой

   ```
   npx tsx tools/slice.ts art/*.png
   ```

   Инструмент удалит пурпурный фон, найдёт объекты, разложит их по именам (`assets/sprites/hull_scout_1.png` …) и нарисует контактные листы для проверки в `tools/out/`.
4. Проверка в игре: `dist/index.html?dev=art` — витрина всей графики (зелёные подписи — уже из картинок).

Сами листы в сборку не попадают — только нарезанные файлы из `assets/sprites`.
