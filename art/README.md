# Листы иконок и эффектов

Отсюда берутся значки интерфейса и кадры эффектов (взрывы, огонь, дым, вспышки выстрела):

- `10_icons.png`, `10_icons_2.png`, `10_icons_3.png` — иконки оружия, способностей, улучшений, бонусов;
- `11_effects.png` — кадры эффектов.

Нарезка в `assets/sprites` (WebP, попадают в сборку):

```
npx tsx tools/slice.ts art/10_icons*.png art/11_effects.png
```

Расположение объектов на листах описано в `tools/sheets.ts`. Модели мира (танки, враги, препятствия)
сюда не относятся — они воксельные и собираются кодом в `src/iso/models`.
