# Сюда — сгенерированные листы спрайтов

1. Возьмите готовый промт из папки `art/prompts/` (имя файла = имя будущей картинки) или из `docs/ART_PROMPTS.md`:
   открыли файл → Ctrl+A → Ctrl+C → вставили в ChatGPT. Ничего склеивать не нужно. В первом сообщении чата приложите референс.
2. Сохраните их в эту папку **с именами из заголовков** промтов: `01_hulls_1-4.png`, `03_turrets.png`, `13_ground_3.png` и т. д. (PNG, WebP или JPEG). Вариант перегенерации можно назвать `01_hulls_1-4 (2).png`.
3. Скажите мне — я нарежу их командой

   ```
   npx tsx tools/slice.ts art/*.png
   ```

   Инструмент удалит пурпурный фон, найдёт объекты, разложит их по именам (`assets/sprites/hull_scout_1.png` …) и нарисует контактные листы для проверки в `tools/out/`.
4. Проверка в игре: `dist/index.html?dev=art` — витрина всей графики (зелёные подписи — уже из картинок).

Сами листы в сборку не попадают — только нарезанные файлы из `assets/sprites` (WebP).

Состояние: нарезаны все листы, включая поверхности `13_ground_1` … `13_ground_8`.

## Размеры картинок в игре

`npm run dev` → http://localhost:5173/?dev=tune — слева ползунки (группы и каждая картинка), справа игра
с этой графикой (бессмертие, выбор мира 1–8, «Убить босса → переход», скорость игры).
Кнопка «Сохранить в проект» пишет `assets/sprites/scales.json`; из файла масштабы попадают в сборку.
В `dist/index.html?dev=tune` сохранить в проект нельзя — там кнопка «Скачать scales.json».
