# Промты для генерации графики (ChatGPT / любой генератор изображений)

Как пользоваться:
1. В каждый запрос вставляйте сначала **«Общий стиль»**, затем текст нужного листа.
2. Прикладывайте к первому запросу картинку-референс — так стиль будет ближе.
3. Сохраняйте результат как PNG (или WebP) с именем из заголовка листа, например `01_hulls_1-4.png`, **в папку `art/` проекта** (см. `art/README.md`). Нарезку, удаление фона, масштаб и перекраску под второго игрока я делаю сам (`tools/slice.ts`).
   Картинки, вставленные прямо в чат, я вижу, но сохранить в файл не могу — поэтому нужна папка.
4. Если какой-то объект вышел плохо — перегенерируйте только этот лист, остальное не трогайте.
5. Порядок важности: сначала листы 1–3 (танки игроков) и 10–11 (иконки, эффекты), потом враги и боссы, потом окружение.

---

## Общий стиль (вставлять в начало каждого запроса)

```
Нарисуй игровые спрайты в стиле приложенного референса: современный детализированный пиксель-арт, насыщенные цвета, чёткий тёмный контур, объёмное освещение сверху-слева, яркие блики на металле, у продвинутых моделей — светящиеся синие энергетические детали. Это лист спрайтов для 2D-игры про танки.
Строгие требования к листу:
- фон сплошной чистый пурпурный #FF00FF, без градиентов, без пола, без теней на фоне;
- каждый объект отдельно, в ровной сетке, с большими промежутками, ничего не касается краёв и соседей;
- все объекты одного листа в одном масштабе;
- без текста, без подписей, без цифр, без рамок и без интерфейса;
- никаких логотипов и узнаваемых персонажей из других игр.
```

## Как это попадает в игру (для справки)

- Каждый объект становится файлом `assets/sprites/<ключ>.png`; раскладка «лист → ключи» — в `tools/sheets.ts`.
- Корпуса и башни игроков, враги, боссы, снаряды поворачиваются игрой (32 угла), поэтому рисуются строго сверху и носом вправо.
- Игра уменьшает картинку до размера на экране со сглаживанием, делает чёткий силуэт и тёмный контур в 1 пиксель — получается пиксель-арт той же детальности, что и экран.
- Если картинки нет, рисуется прежний процедурный спрайт — листы можно добавлять по одному.
- Цвет второго игрока (зелёный) получается автоматической перекраской золотых деталей.
