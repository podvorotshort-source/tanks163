# Баланс — цели, рычаги, последние замеры

## Цели (решение пользователя, 17.10.2026)

> «игра не должна проходиться с первого раза, для этого и существует мастерская. Игрок долго должен
> проходить, совершая попытки, ища лучшую синергию и делая улучшения в мастерской… финал с глобусом
> должен быть кульминацией страдания игрока».

- Свежий профиль (без мастерской, стартовые открытия): гибель на 2–4-й ступени.
- Полная мастерская + открытия + удачная синергия + хорошая игра: победа возможна, но тяжела.
- Полная прокачка всего — несколько десятков забегов (мастерская 13 430 деталей + открытия ~3 900;
  забег даёт ~300–900, победа ~3 000).
- Бой с боссом 45–90 с, ступень 6–7 мин, полный забег ~60 мин.

## Как мерить

```bash
npx tsx tools/sim.ts --classes scout --seed 610 --max 4200          # полный забег ботом
npx tsx tools/sim.ts --classes assault,heavy --seed 710 --max 4200  # вдвоём
npx tsx tools/sim.ts --classes heavy --seed 600 --max 1150 -v       # первые ступени с событиями
npx tsx tools/sim.ts --classes scout --skill 1 --meta 1              # лучший бот с полной мастерской
npx tsx tools/workshop-cost.ts                                       # стоимость всей прокачки
npx tsx tools/analyze.ts ...                                         # поминутная раскладка
```

Вывод: время каждой ступени, длительность боя с боссом, уровень, **урон по боссу по источникам**
(`he:he*` — со звёздочкой попадания в слабое место) и урон по игрокам по источникам.
Боты (`src/sim/bot.ts`) уклоняются хуже человека — их результат это нижняя граница.
Прокачка мастерской задаётся `--meta` (0 — новый игрок, 1 — всё вкачано и открыто), угроза — `--threat`.

## Что ещё настроить

- Тяжёлый: бой с 4-м боссом (холодильник) у бота длился 5+ мин — огнемёт не подъезжает. Проверить людьми.
- Если с полной прокачкой победа окажется недостижимой — ослаблять `STAGE_HP_K/STAGE_DMG_K` на 7–8-й ступени.
- Главный источник урона по игрокам — снаряды танков (`shot:shell`); если живые игроки
  будут жаловаться — снижать `ENEMY_FIRE_K` или скорость снарядов.
- Повышенные уровни сложности (угрозы) — проверены только на расчётах, не прогонами.
