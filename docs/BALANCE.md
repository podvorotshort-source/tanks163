# Баланс — цели, рычаги, последние замеры

Цели (из ответов пользователя): полный успешный забег ≈ 60 минут, базовая сложность прощающая,
бой с боссом 45–90 с, 12–15 уровней на ступень.

## Как мерить

```bash
npx tsx tools/sim.ts --classes scout --seed 610 --max 4200          # полный забег ботом
npx tsx tools/sim.ts --classes assault,heavy --seed 710 --max 4200  # вдвоём
npx tsx tools/sim.ts --classes heavy --seed 600 --max 1150 -v       # первые ступени с событиями
npx tsx tools/analyze.ts ...                                         # поминутная раскладка
```

Вывод: время каждой ступени, длительность боя с боссом, уровень, **урон по боссу по источникам**
(`he:he*` — со звёздочкой попадания в слабое место) и урон по игрокам по источникам.
Боты (`src/sim/bot.ts`) уклоняются хуже человека и не получают бонусов мета-прогрессии —
их результат это нижняя граница.

## Главные рычаги

| Что | Где | Сейчас |
|---|---|---|
| Кривая опыта | `sim.ts` `XP_K`, `xpNeed`, убывание после 13 уровней на ступени | 1.3 |
| Урон игроков | `upgrades.ts` `PLAYER_DMG_K` | 1.25 |
| Огонь врагов | `enemyRun.ts` `ENEMY_FIRE_K` | 1.5 |

| Классы | `content/classes.ts` | Тяжёлый: 205 HP, броня 38% |

## Последние замеры (17.10.2026, боты skill 0.7, без мета-бонусов)

- Разведчик (seed 610): дошёл до 7-й ступени за 2830 с (47 мин), ур. 113; бои с боссами 42 / 37 / 101 / 60 / 61 / 57 с.
- Штурмовик + Тяжёлый (seed 710): 6-я ступень за 2453 с, ур. 90; бои 56 / 53 / 77 / 89 / 99 с.
- Штурмовик один: погибает на 1–2-й ступени (бой с боссом 36–58 с, гибнет от снарядов).
- Тяжёлый один: бой с первым боссом 165–198 с — всё ещё долго; гибнет на 1–2-й ступени.
- Ступени длятся 385–450 с → 8 ступеней ≈ 55–60 мин с переходами.

## Что ещё настроить

- Тяжёлый в одиночку: ближний бой с боссом слишком долгий (огнемёт) — проверить людьми.
- Главный источник урона по игрокам — снаряды танков (`shot:shell`); если живые игроки
  будут жаловаться — снижать `ENEMY_FIRE_K` или скорость снарядов.
- Повышенные уровни сложности (угрозы) — проверены только на расчётах, не прогонами.
