# REQUIREMENTS — чек-лист по исходному ТЗ пользователя

Сжатый, но полный перечень требований мастер-промпта. Отмечать `[x]` только
после реальной проверки (тестом или в браузере). Ссылки на проверки — в `SYSTEMS.md`.

## Масштаб мира
- [ ] Старт: маленький танк на игрушечном поле в духе Dendy
- [ ] Танк растёт относительно окружения по мере уровней
- [ ] После босса — зрелищное отдаление камеры, прежняя арена — часть большего мира
- [ ] Во время перехода танк НЕ меняет размер, раскрывается мир
- [ ] После перехода танк продолжает расти в новом окружении
- [ ] 8 ступеней (игрушки → ковёр/детская → комната → дом → улицы → мегаполис → танки-города → планета)
- [ ] С масштабом меняются окружение, враги, препятствия, боссы, характер боя
- [ ] Мелкие враги прошлого масштаба не опасны (давятся)

## Графика
- [ ] Оригинальная пиксельная графика, без чужих ассетов
- [ ] Узнаваемые силуэты, анимации движения/стрельбы/попаданий/уничтожения
- [ ] Взрывы, огонь, искры, дым, обломки; свет от взрывов
- [ ] Читаемые снаряды и опасные атаки (телеграфирование)
- [ ] Эффекты появления боссов и переходов
- [ ] Ясность при большом количестве врагов и эффектов

## Геймплей
- [ ] Опыт мгновенно за убийство, без сфер/подбора; сильные враги дают больше
- [ ] Общая шкала опыта команды → пауза → оба выбирают личное улучшение
- [ ] Выбор без неудобного ожидания второго игрока
- [ ] Несколько вариантов, учитывают оружие, билд, синергии; несовместимое не предлагается
- [ ] Элиты, события, боссы; разный темп; тактические решения

## Кооператив
- [ ] 1P: WASD; 2P: стрелки; способности без конфликтов клавиш; Num0/Num1 для 2P
- [ ] Мышь не обязательна; управление можно посмотреть в интерфейсе
- [ ] DualShock 4 / DualSense: движение, способности, меню; удобное подключение
- [ ] Дружественный огонь: никакого урона, оглушения, замедления, отбрасывания
- [ ] Бонусы действуют на обоих; один бонус = один эффект (граната — один раз)
- [ ] Индивидуальные билды

## Смерть и спасение
- [ ] Свои жизни у каждого
- [ ] Подбитый танк можно спасти, стоя рядом; спасение не тратит жизнь
- [ ] Неудачное спасение → корректная потеря жизни и возрождение; нет бесконечных бесплатных возвращений
- [ ] Работает на боссах (реально выполнимо)
- [ ] Визуально понятное состояние подбитого танка, индикатор спасения

## Бонусы (классика)
- [ ] Звезда, Часы, Каска, Граната, Лопата, Доп. жизнь (+ свои)
- [ ] Понятные иконки и приятная обратная связь
- [ ] Граната и др. масштабируются (не убивают босса)
- [ ] Временные бонусы отличаются от постоянных улучшений

## Классы
- [ ] Разведчик (скорость, рывок), Штурмовик (универсал, залп), Тяжёлый (броня, неуязвимость)
- [ ] Оружие не заперто за классом; индивидуальность классов на поздних масштабах

## Оружие
- [ ] Пулемёт, Пушка/бронебойные, Фугасы, Ракеты+артиллерия (одна категория), Огнемёт/напалм, Мины (+ свои)
- [ ] У каждого роль, сильные и слабые стороны; нет «лучшего во всём»
- [ ] Броня/уязвимости/сопротивления врагов и боссов

## Улучшения и синергии
- [ ] Общие (радиус взрыва ≠ радиус огня), оружейные (только при наличии), синергии
- [ ] Разнообразие забегов, но возможность вести стратегию

## Боссы и враги
- [ ] Уникальные силуэты, атаки, поведение, слабые места, призыв, опасные зоны
- [ ] Соответствуют масштабу; серьёзная, но преодолимая угроза
- [ ] Обычные и элитные враги различаются поведением

## Окружение и события
- [ ] Разрушаемость разных материалов; неразрушаемые границы
- [ ] Разрушение меняет поле боя (проходы, укрытия, обломки, огонь)
- [ ] Производительность разрушений
- [ ] Динамические события (ящики, элиты, опасные зоны, артобстрел, оборона штаба)

## Мета-прогрессия
- [ ] Мастерская, Арсенал, Исследования, Гараж, Трофеи/косметика
- [ ] Простая экономика (одна валюта), без обязательного гринда
- [ ] Новый забег с нуля по временной прокачке; постоянное сохраняется
- [ ] Награда за проигранный забег; общий прогресс для кооператива

## Сохранения и интерфейс
- [ ] Прогресс переживает перезагрузку; повреждённые/отсутствующие сохранения обрабатываются
- [ ] Экраны: запуск, режим и класс, управление, HUD, пауза, уровень, результаты, мастерская
- [ ] Нет декоративных неработающих кнопок

## Звук
- [ ] Двигатели, выстрелы по типам, попадания, взрывы, разрушения, бонусы, уровень, босс, переходы
- [ ] Громкость и выключение звука; музыка

## Тестирование (см. SYSTEMS.md, PLAYTEST.md, BALANCE.md)
- [ ] Всё из раздела 16 ТЗ проверено; непроверенное честно отмечено
