Варианты графики «Танкороста» — без пикселей

Одна и та же сцена в четырёх стилях: игрушечный танк (модель I) и титан (модель VIII), игрушечные враги, кирпич, сталь, куст, бонус, выстрел и взрыв. Всё нарисовано кодом — так же будет рисовать игра.

Двигайте приближение: в любом из вариантов края остаются гладкими — без «лесенки» пикселей.
Выберите вариант (или сочетание: например, «мультяшный» с неоновыми эффектами поздних миров) — напишите номер в чате.
